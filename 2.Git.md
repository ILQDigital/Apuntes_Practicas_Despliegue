# Configuración e Instalación de Git en el VPS

Esta guía explica cómo instalar y configurar **Git** dentro de tu servidor VPS para automatizar el despliegue de código y evitar la transferencia manual de archivos.

---

## ¿Por qué instalar Git dentro del VPS?

**Git** es el sistema de control de versiones que registra los cambios en tu código fuente, y **GitHub** es la plataforma web donde se aloja el repositorio remoto.

Instalar Git **dentro del VPS** te permite sincronizar el código de producción de forma inmediata:
- En tu PC local: Subes los cambios al repositorio remoto (`git push`).
- En el VPS: Descargas las actualizaciones con un único comando (`git pull`).

> [!NOTE]
> Todos los comandos detallados en este manual deben ejecutarse **dentro del VPS** tras conectarse por SSH (ver [1.VPS.md](1.VPS.md)).

---

## 1. Instalación de Git

Accede al VPS e instala el paquete oficial de Git mediante el gestor de paquetes de Ubuntu/Debian (`apt`):

```bash
sudo apt update && sudo apt install git -y
```

- `apt`: Es el gestor de paquetes del sistema operativo.
- `sudo`: Ejecuta la instalación con privilegios de administrador.

### Verificar la instalación:

```bash
git --version
```

*(Si el comando devuelve la versión de Git instalada, el proceso ha finalizado correctamente).*

---

## 2. Configuración inicial de usuario en Git

Git requiere identificar al autor de los cambios guardados en los *commits*. Esta configuración actúa como la firma de los registros dentro del historial.

```bash
git config --global user.name "tu nombre"
git config --global user.email "tucorreo@ejemplo.com"
```

- `--global`: Aplica esta configuración a todos los repositorios gestionados por el usuario actual en esta máquina.

### Verificar la configuración guardada:

```bash
git config --global --list
```

---

## 3. Autenticación SSH entre el VPS y GitHub

> [!IMPORTANT]
> **Diferencia entre las claves SSH del sistema:**  
> - **Clave PC $\rightarrow$ VPS:** Creada en [1.VPS.md](1.VPS.md) para conectarte desde tu ordenador al servidor.  
> - **Clave VPS $\rightarrow$ GitHub:** Debe generarse **dentro del VPS** para autorizar a la máquina virtual a clonar repositorios privados y descargar actualizaciones desde GitHub.

### Paso 3.1: Generar la clave dentro del VPS

```bash
ssh-keygen -t ed25519 -C "vps-git"
```

Pulsa `Enter` a todo (acepta la ruta por defecto). Se crean dos archivos en `~/.ssh/`: la clave privada (no se comparte) y la pública (`.pub`).

### Paso 3.2: Dar la clave pública a GitHub

Muestra la clave pública y cópiala entera:

```bash
cat ~/.ssh/id_ed25519.pub
```

En GitHub: *Settings > SSH and GPG keys > New SSH key*, y pégala.

### Paso 3.3: Probar la conexión

```bash
ssh -T git@github.com
```

Debe responder con un saludo con tu usuario de GitHub (*"Hi usuario! You've successfully authenticated..."*). Ya puedes usar `git clone git@github.com:usuario/repositorio.git`.

---

## 4. Configurar el editor de texto por defecto

Cuando Git requiere introducir mensajes o resolver conflictos (como en un `git commit`), abre un editor en consola. Por defecto suele abrir `vim`. Para utilizar `nano` (más sencillo e intuitivo), establece la siguiente regla:

```bash
git config --global core.editor "nano"
```
