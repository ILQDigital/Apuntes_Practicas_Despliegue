# Cómo Realizar Copias de Seguridad (Backups) en el VPS

Esta guía explica cómo realizar una copia de seguridad comprimida (`.tar.gz`) de los datos persistentes de tus aplicaciones desplegadas en Docker y cómo descargarlos a tu ordenador local.

> [!NOTE]
> Los pasos 1 al 5 se ejecutan **dentro del VPS** vía SSH. El paso 6 se ejecuta **en la terminal de tu ordenador local**.

---

## 1. Conectarse al VPS por SSH

Accede a la máquina virtual desde la terminal de tu equipo:

```bash
ssh usuario@ip_vps
```

---

## 2. Averiguar la ruta exacta de los datos en el VPS (*Bind Mount*)

Para saber dónde guarda los datos el contenedor en el disco del VPS, inspecciona sus puntos de montaje con `docker inspect`:

```bash
docker inspect nombre_contenedor --format '{{json .Mounts}}'
```

### Ejemplo del resultado JSON devuelto:

```json
[{"Type":"bind","Source":"/home/uservps/nombre_carpeta","Destination":"/app","Mode":"","RW":true,"Propagation":"rprivate"}]
```

- **`Source` (`/home/uservps/nombre_carpeta`):** Es la ruta real en el VPS donde residen los datos persistentes (bases de datos SQLite, archivos cargados, CSV, etc.).
- **`Destination` (`/app`):** Es la ruta interna dentro del contenedor.

---

## 3. Crear la carpeta para guardar los backups

Crea un directorio en el VPS dedicado a almacenar las copias de seguridad y entra en él:

```bash
mkdir -p ~/backups
cd ~/backups
```

---

## 4. Generar el archivo de backup comprimido (`.tar.gz`)

Ejecuta el comando `tar` para empaquetar y comprimir la carpeta de datos.

### Opción A: Guardando la ruta completa del directorio

```bash
tar -czf backup_app.tar.gz /home/uservps/nombre_carpeta
```

### Opción B: Guardando solo el contenido e incluyendo la fecha (Recomendado)

```bash
tar -czf backup_$(date +%Y%m%d).tar.gz -C /home/uservps/nombre_carpeta .
```

### Desglose de los parámetros del comando:
- `-c` (*create*): Crea un nuevo archivo de copia de seguridad.
- `-z` (*gzip*): Comprime el archivo en formato `.tar.gz` para reducir su tamaño.
- `-f` (*file*): Especifica el nombre del archivo comprimido resultante.
- `-C /home/uservps/nombre_carpeta`: Cambia la ubicación de trabajo al directorio indicado antes de realizar la copia.
- `.` (el punto final): Indica que debe empaquetar **todo el contenido** de esa carpeta sin incluir las carpetas superiores (`/home/uservps/...`).
- `$(date +%Y%m%d)`: Agrega la fecha actual automáticamente al nombre del archivo (por ejemplo, `20260814`).

> [!TIP]
> **Diferencia entre ambas opciones:**  
> - En la **Opción A**, al descomprimir el archivo se volverá a crear la estructura completa de carpetas (`/home/uservps/nombre_carpeta`).
> - En la **Opción B** (usando `-C` y `.`), el backup contendrá directamente los archivos de la app, lo que facilita una restauración más limpia.

---

## 5. Verificar que la copia se ha creado correctamente

Comprueba el contenido del directorio `~/backups` y el tamaño del archivo generado:

```bash
ls -lh
```

> Deberías ver el archivo `backup_YYYYMMDD.tar.gz` con un tamaño razonable (distinto de 0 bytes).

---

## 6. Descargar el backup a tu ordenador local

Para transferir las copias de seguridad desde el servidor remoto a tu equipo:

1. Abre una **nueva terminal en tu ordenador local** (fuera del VPS).
2. Sitúate en la carpeta local donde quieras descargar los archivos (ej. Descargas o Documentos).
3. Ejecuta el comando `scp`:

```bash
scp usuario@servidor:/home/uservps/backups/backup_20260814.tar.gz .
```

*(El punto final `.` indica que el archivo se copiará dentro de la carpeta local en la que te encuentras).*

---

## 7. (Opcional) ¿Cómo restaurar una copia de seguridad?

Si necesitas restaurar los archivos guardados previamente dentro de la carpeta del VPS:

```bash
tar -xzf backup_20260814.tar.gz -C /home/uservps/nombre_carpeta
```
